# 따릉이 서울 여행

서울 지도에서 원하는 도착지를 직접 찍고, 현재 위치에서 그곳까지 자전거 길을 확인하는 웹사이트입니다. 추천 코스와 따릉이 대여소 정보도 볼 수 있습니다. 타자 게임은 별도로 열 수 있는 부가 기능입니다.

- [사이트 열기](https://seoul-ttareungi-typing.vercel.app/)
- [GitHub Pages](https://hayul090615.github.io/bicycle/)

## 사용 방법

1. 사이트를 열고 현재 위치 사용을 허용합니다.
2. 상단의 **지도에서 원하는 곳 선택**을 누릅니다.
3. 서울 지도 안에서 가고 싶은 지점을 누릅니다. 미리 정해진 도착지 목록을 고를 필요가 없습니다.
4. 지도에 표시된 자전거 경로, 거리, 예상 시간, 다음 이동 방향을 확인합니다.
5. 따릉이를 이용한다면 **1시간** 또는 **2시간**을 눌러 반납 타이머를 시작합니다.

## 현재 제공하는 기능

### 목적지 선택과 길찾기

- 출발지는 **내 위치**로 표시하며, 출발지 목록을 고르는 방식은 사용하지 않습니다.
- 서울 지도에서 임의의 지점을 도착지로 선택하고 다시 선택하거나 해제할 수 있습니다.
- 지도에서 출발 위치는 초록색 **출발** 핀, 선택한 도착지는 빨간색 **도착** 핀으로 구분합니다.
- 위치 권한을 허용하면 GPS로 현재 위치를 표시하고, 정확도 범위와 **내 위치** 버튼을 제공합니다.
- 선택한 도착지까지 자전거 경로를 표시합니다. 경로 서비스가 방향 정보를 제공하면 다음 회전 방향과 구간별 길 안내도 표시합니다.
- 이동 거리와 예상 자전거 시간을 표시합니다.
- 관광·운동·야경·계절별 추천 코스를 둘러볼 수 있습니다. 추천 코스는 자유롭게 찍는 도착지와 별개입니다.
- 추천 코스를 검색하고, 내 위치에서 가까운 코스·강변 평탄 코스·예상 주행 시간(약 30분/1시간)·코스 종류로 골라볼 수 있습니다.
- 선택한 경로의 고도 그래프, 누적 오르막, 지도에 기록된 신호등·오르막·내리막 정보를 확인할 수 있습니다. 자료를 불러오지 못하면 표시되지 않을 수 있습니다.
- 모바일에서는 지도 아래 경로 요약과 코스 패널을 열 수 있습니다.

### 지도와 주변 정보

- 2D 지도, 3D 도시 지도, 위성 지도를 전환할 수 있습니다.
- 서울 경계를 검은 선으로 표시하고 서울 밖 지도는 흐리게 표시합니다. 지도 도착지 선택은 서울 안에서만 가능합니다.
- 지도 설정에서 계절, 날씨 표현, 건물 그림자 표시를 바꿀 수 있습니다.
- 자전거도로, 공공 CCTV 설치 위치, 신호등·경사, 화장실 등 편의시설 표시를 켜고 끌 수 있습니다. CCTV 실시간 영상은 제공하지 않습니다.
- 한국어와 영어 화면을 전환할 수 있으며, 영어 화면에서는 지원 지도 화면의 지명도 영어로 표시합니다.
- 밝은 화면과 어두운 화면을 전환할 수 있습니다.

### 따릉이 대여와 반납 시간

- 위치를 확인하면 주변 따릉이 대여소를 보여줍니다. 실시간 API를 사용할 수 있는 경우 잔여 자전거 수도 표시합니다.
- 현재 위치에서 선택한 대여소까지의 도보 경로와 대여소에서 목적지까지의 자전거 경로를 확인할 수 있습니다.
- **1시간·2시간** 중 하나를 누르면 디지털 반납 타이머가 시작됩니다. 시작·종료 버튼으로도 타이머를 조작할 수 있습니다.
- 페이지를 열어 두고 브라우저 알림을 허용하면 만료 5분 전과 만료 시점에 알림을 받습니다. 남은 시간은 화면에도 표시됩니다.

### 부가 기능

- 시작할 때 흰 화면 중앙에 자전거 애니메이션이 나온 뒤 지도가 열립니다.
- 모바일·태블릿·데스크톱 화면 크기에 맞춰 배치가 바뀝니다.
- **타자 게임**에서는 서울 25개 자치구 코스를 선택해 대여소 이름을 입력할 수 있습니다. 시작 전 3초 카운트다운, 점수·정확도·콤보·진행률, 일시 정지, 결과 화면과 브라우저 최고 점수 저장 기능이 있습니다.
- 타자 게임 화면에서 별도의 문장 타자 연습도 열 수 있습니다.

## 화면 구성

| 영역 | 할 수 있는 일 |
| --- | --- |
| 상단 경로 설정 | 내 위치를 출발지로 확인하고 지도에서 도착지를 선택합니다. 필요한 경우 경유지를 설정합니다. |
| 지도 | 경로, 출발·도착 핀, 현재 위치, 다음 이동 방향과 선택한 지도 정보를 확인합니다. |
| 코스 목록 | 추천 코스를 검색하고 주행 시간·코스 종류·평탄한 강변 코스로 걸러 봅니다. |
| 반납 시간 카드 | 1시간 또는 2시간을 고르고 남은 시간을 확인합니다. |
| 타자 게임 | 별도 화면에서 자치구별 대여소 이름 타자 게임과 문장 연습을 엽니다. |

추천 코스는 정해진 경유지를 살펴보는 기능입니다. **자유 목적지 길찾기**는 지도에서 원하는 서울 시내 지점을 직접 눌러 이용합니다. 두 기능은 별도로 사용할 수 있습니다.

## 사용 시 알아둘 점

- 현재 위치 출발 경로에는 브라우저의 위치 권한이 필요합니다. 실제 위치 정확도는 기기와 GPS 수신 상태에 따라 달라집니다.
- 자전거 경로 서비스에 연결되지 않으면 상세 방향 안내를 불러오지 못할 수 있습니다. 지도에 남는 연결선은 실제 주행 가능한 길이라는 보장이 없습니다.
- 실시간 대여 정보가 없으면 대여소 위치 자료를 보여주고 잔여 대수는 알 수 없음으로 표시합니다.
- 반납 타이머는 사용자가 시작하는 화면용 타이머이며 실제 따릉이 대여 기록과 자동으로 연결되지 않습니다.

## 개발 및 실행

React, TypeScript, Vite를 사용합니다. 지도에는 MapLibre GL과 Leaflet을 사용하며, 자전거 길은 외부 경로 서비스를 요청합니다.

```bash
npm install
npm run dev
```

Windows PowerShell에서 `npm.ps1` 실행이 막히면 `npm.cmd install`, `npm.cmd run dev`를 사용합니다.

```bash
npm run build
npm run preview
```

빌드 결과는 `dist/`에 생성됩니다. 실시간 따릉이 잔여 대수를 제공하려면 서버 환경 변수 `SEOUL_BIKE_API_KEY`가 필요합니다. 키가 없어도 포함된 대여소 위치 자료로 지도를 사용할 수 있습니다.
