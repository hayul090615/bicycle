# 2026-10-01 지도 UI 및 모바일 동작 기록

배포 사이트: https://hayul090615.github.io/bicycle/

## 추가된 기능

+ 코스 목록을 처음에는 접어서 표시하고 지도 영역이 빈 열 없이 화면 폭을 채우도록 했습니다.
+ 초록 지도 도구를 넓은 두 칸 버튼 배열로 바꿨습니다. 데스크톱에서는 코스 열기 손잡이와 같은 세로 길이로 배치합니다.
+ 지도 확대·축소 버튼을 오른쪽 위에 두어 초록 메뉴와 겹치지 않게 했습니다.
+ 모바일 화면은 지도 위, 도구 버튼 아래 순서로 배치합니다. 모바일 지도는 화면 폭 전체를 사용하고, 도구 버튼은 두 칸으로 정렬됩니다.
+ 3D 도시 및 2D 위성 전환 버튼을 따로 두고, 눌러도 빈 흰색 설명 패널이 열리지 않게 했습니다. 활성 보기에는 초록 선택 표시를 적용했습니다.
+ 코스 패널에서 부가 설명과 중복 태그를 줄이고 코스명, 거리·예상 시간, 고도 그래프, 대여소 정보, 계절 선택을 중심으로 보이게 했습니다.
+ 내 위치를 누르면 watchPosition으로 위치 변화를 계속 받아 마커 위치를 갱신합니다. 방향 센서의 방위가 없으면 연속 위치로 이동 방위를 계산해 화살표에 반영합니다.

## 모바일 동작 확인

Chrome 모바일 에뮬레이션에서 화면 크기 393×852 CSS 픽셀, 기기 배율 2로 확인했습니다. 실제 휴대전화의 GPS가 아니라 브라우저에 모의 위치를 전달해 테스트했습니다.

+ 지도 영역은 x=0, y=60, 폭=393, 높이=494 픽셀이었고, 도구 막대는 y=563에서 시작해 지도 아래에 표시됐습니다.
+ 확대·축소 버튼은 지도 오른쪽 위(x=338, y=71)에 표시되어 도구 막대와 겹치지 않았습니다.
+ 3D 버튼은 지도 3D 요소를 표시했고 설명 패널은 열리지 않았습니다. 2D 버튼도 위성 보기로 전환했고 설명 패널은 열리지 않았습니다.
+ 서울 좌표에서 동쪽으로 이동한 모의 GPS 업데이트 뒤 위치 화살표 방위가 약 72.5도로 바뀌었고, 북쪽 이동 업데이트 뒤 0도로 바뀌었습니다. 마커 위치도 업데이트됐습니다.
+ 브라우저 런타임 오류는 없었습니다. 데스크톱 1280×900에서도 지도 도구 막대와 코스 손잡이 높이가 각각 828픽셀로 같고 확대·축소 버튼은 우측 상단에 있는 것을 확인했습니다.

실제 휴대전화에서는 HTTPS 사이트에 위치 권한을 허용해야 실시간 GPS를 받을 수 있습니다. 위치 서비스가 꺼져 있거나 권한이 거부되면 브라우저 제한으로 추적되지 않습니다.
