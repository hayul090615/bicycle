# 코드 읽기 안내 — 고등학생도 따라갈 수 있게

프로젝트에서 직접 관리하는 TypeScript·React·JavaScript 소스에는 파일의 역할과 주요 함수·처리 흐름을 한국어 주석으로 설명했습니다. CSS·HTML·SVG·SQL·배포 YAML에는 해당 형식에 맞는 주석을 사용했습니다. 설명 주석은 실행 코드를 비활성화하지 않습니다.

## 먼저 알아둘 문법

| 코드 | 쉬운 설명 |
| --- | --- |
| `// 설명`, `/* 설명 */` | 사람이 읽는 메모입니다. 프로그램은 실행하지 않습니다. |
| `const`, `let` | 값에 이름을 붙입니다. `const`는 다시 대입하지 않고, `let`은 새 값을 대입할 수 있습니다. |
| `function`, `=>` | 여러 동작을 묶은 함수입니다. 이름 뒤에 `()`를 붙이면 실행합니다. |
| `if`, `return` | 조건에 맞으면 실행합니다. `return`을 만나면 그 함수는 끝납니다. |
| `for`, `.map()`, `.filter()` | 여러 항목을 차례로 처리합니다. `map`은 바꾸고, `filter`는 조건에 맞는 항목만 남깁니다. |
| `async`, `await` | 지도 자료처럼 늦게 오는 결과를 기다립니다. 기다리는 동안 화면의 다른 기능은 계속 동작할 수 있습니다. |
| `try`, `catch` | 먼저 시도하고, 실패했을 때의 처리를 적습니다. |
| `type`, `interface` | 값이 어떤 모양이어야 하는지 적습니다. 실수로 문자열과 숫자를 섞는 일을 줄입니다. |
| `<button>...</button>` | React에서 화면을 만드는 JSX입니다. HTML처럼 읽으면 됩니다. `{}` 안에는 계산이나 함수가 들어갑니다. |

## React가 값을 기억하는 방법

- `useState`: 화면에 필요한 값입니다. `set...` 함수로 바꾸면 화면에도 반영됩니다.
- `useRef`: 지도 객체나 이전 위치를 넣어 두는 상자입니다. `.current`로 읽고 바꾸며, 이 값만 바꿔서는 화면이 다시 그려지지 않습니다.
- `useEffect`: 화면이 열리거나 지정한 값이 바뀌면 동작합니다. 안에서 돌려준 함수는 타이머나 위치 추적을 정리합니다.
- `useMemo`: 같은 입력이면 전에 계산한 결과를 다시 씁니다.
- `useCallback`: 다른 화면에 전달할 함수를 기억합니다.

코드에서 `API`는 다른 서비스에 자료를 요청하는 창구, `SDK`는 지도 회사에서 제공하는 도구입니다. `캐시`는 받은 결과를 잠시 저장해 다시 쓰는 방법이고, `GeoJSON`은 지도 좌표를 담는 자료 형식입니다. `포털`은 화면 내용을 다른 HTML 위치에 표시하는 React 기능입니다.

## 실제 기능으로 읽어 보기

### 주변 장소는 한 종류만

대여소는 지도 중심 500m 이내에 기본으로 항상 표시합니다. 별도의 대여소 버튼은 없습니다.

`TourRouteExplorer.tsx`의 `discoveryCategory`는 추가로 볼 `'cctv'`, `'food'` 같은 값 하나만 기억합니다. 맛집을 누르면 값이 `'food'`로 바뀌므로 CCTV 표시는 꺼집니다. 같은 버튼을 다시 누르면 `null`이 되어 추가 표시를 끕니다. 대여소와 경로, 현재 위치는 계속 보입니다.

`useNearbyPlaces.ts`는 지도를 옮긴 뒤 0.35초 기다렸다가 새 위치를 검색합니다. 지도 중심과 장소 사이의 거리를 계산해서 **500m 이내**만 남깁니다. 이전 검색이 늦게 도착하면 취소된 요청인지 확인하고 버립니다.

CCTV는 실제 GPS의 내 위치에서 **20m 이내**만 표시합니다. 내 위치가 없으면 위치 접근을 요청하고, 허용되지 않으면 카메라를 표시하지 않습니다.

### 1시간·2시간 이용시간

`startRentalTimer(60)`에서 60은 분입니다. `Date.now()`는 현재 시각을 밀리초로 줍니다.

```ts
// 현재 시각에 60분을 더해 끝나는 시각을 만든다.
const end = Date.now() + 60 * 60_000
// 끝나는 시각에서 현재 시각을 빼고 초로 바꾼다.
const remainingSeconds = Math.max(0, Math.ceil((end - Date.now()) / 1000))
```

숫자의 `_`는 읽기 쉽게 넣는 구분 표시입니다. `60_000`과 `60000`은 같습니다. 끝나는 시각을 저장하므로 화면을 다시 열어도 시간이 처음부터 시작되지 않습니다.

### 로드뷰 도착 버튼

`RoadviewDestinationControl.tsx`는 버튼 클릭 → 목적지 주변 사진 검색 → 사진 이동 → 실제 사진 번호·촬영 위치 확인 → 축하 안내 순서입니다. 여기서 이동하는 것은 거리 사진이며, 사용자의 실제 GPS를 바꾸지는 않습니다.

### 좌표 순서와 거리

`lat`는 위도, `lng`는 경도입니다. 이 프로젝트의 경로 배열은 **[경도, 위도]**이고 Leaflet의 위치 배열은 **[위도, 경도]**입니다. 순서를 바꾸면 다른 곳이 표시됩니다. 거리 계산은 미터, 타이머는 밀리초와 초를 사용하므로 각 파일의 주석에서 단위를 확인하세요.

`seoulBikeServiceBoundary.ts`는 서울 모양에서 바깥 대여소 주변만 220m 확장한 범위 좌표입니다. 지도에서는 검정 선을 그리지 않고, 바깥 지역을 흐리게 하는 범위와 장소 선택 범위에 사용합니다. `node scripts/build-bike-service-boundary.mjs`로 다시 만듭니다. 공식 행정 경계 자료와는 다릅니다.

## 코드가 연결되는 순서

1. `index.html`이 `src/main.tsx`를 불러오고 React 화면을 연결합니다.
2. `src/App.tsx`가 지도 여행·타자 게임·인증 화면과 시작 애니메이션을 관리합니다.
3. 지도 여행은 `TouristGuide.tsx` → `TourRouteExplorer.tsx` → 지도 SDK 컴포넌트 순으로 연결됩니다.
4. `services/`는 외부 조회와 저장을, `hooks/`는 React 상태와 이벤트 수명을 관리합니다. `utils/`는 좌표·문자열·표시 계산을 담당합니다.
5. `api/`의 서버 함수는 서울시·네이버·방문 데이터베이스 요청을 중계합니다. 인증 키는 환경 변수에서 읽습니다.

## 주석 문법이 없는 설정·데이터 파일

JSON과 GeoJSON에는 주석 문법이 없으므로 파일 안에 `//` 또는 `/* */`를 넣지 않습니다. 각 파일의 역할은 아래에서 설명합니다.

| 파일 | 역할 |
| --- | --- |
| `package.json` | 프런트엔드 의존성과 개발·빌드·미리보기 명령을 정의합니다. |
| `api/package.json` | 서버 API의 실행 형식과 Express 의존성을 정의합니다. |
| `package-lock.json`, `api/package-lock.json` | 설치할 의존성 버전을 고정하는 npm 생성 파일입니다. 의존성을 바꾸면 npm으로 갱신합니다. |
| `tsconfig.json` | 앱과 Vite 설정의 TypeScript 프로젝트 참조를 연결합니다. |
| `tsconfig.app.json` | `src/`의 React·TypeScript 검사 옵션을 정의합니다. |
| `tsconfig.node.json` | Node 환경에서 사용하는 Vite 설정의 검사 옵션을 정의합니다. |
| `vercel.json` | Vercel 빌드·서버 API·페이지 경로 연결을 설정합니다. |
| `src/data/seoulBikeStations.json` | 대여소 스냅샷과 출처 날짜를 저장합니다. 지도·코스 생성의 기본 자료입니다. |
| `src/data/seoulDistricts.geojson` | 서울 자치구 이름과 Polygon/MultiPolygon 경계를 저장합니다. 좌표는 `[경도, 위도]` 순서입니다. |
| `src/data/seoulBikeServiceBoundary.ts` | 대여소를 포함한 범위 좌표입니다. 대여소 자료와 구 경계로 생성하며 지도 바깥 흐림·선택 범위에 사용합니다. |
| `public/datasets/seoul-cctv.json.gz` | CCTV 위치·출처 자료의 압축 JSON입니다. `scripts/build-seoul-cctv-data.mjs`로 생성합니다. |

## 환경 설정과 생성 결과

- `.env.example`은 필요한 환경 변수 이름의 예시이고 `.env.local`은 로컬 실행 설정입니다. 변수의 사용 지점은 `src/services/`, `api/`, 배포 워크플로의 주석에서 확인할 수 있습니다.
- `.gitignore`는 의존성·로컬 설정·빌드 결과 등 Git에서 제외할 경로를 정의합니다.
- `dist/`, `docs/assets/`와 배포용 `docs/index.html`은 생성된 결과물입니다. 기능 설명은 원본 소스에 작성하며 번들 파일은 직접 주석으로 수정하지 않습니다.
- `node_modules/`는 설치된 외부 라이브러리입니다. 라이브러리 소스를 직접 바꾸는 대신 이 프로젝트에서 호출하는 부분에 주석을 둡니다.
- PNG·압축 자료 같은 바이너리 파일에는 텍스트 주석을 삽입하지 않습니다.

## 길 안내와 도착 판정

- 실제 GPS 도착은 `useDestinationArrival.ts`에서 좌표의 정확도·관측 시각·연속 관측을 확인합니다.
- 로드뷰 위치는 실제 GPS와 별도로 관리합니다. 사진 전환 뒤 같은 촬영 지점을 다시 확인하고, 목적지 10m 이내이면서 경로가 6m 이하 남은 경우 축하 안내를 표시합니다.
- 지도에서 선택한 목적지 핀과 로드뷰의 이동 버튼은 별개입니다. 로드뷰의 파란 ‘도착’ 버튼과 상단 ‘도착’ 버튼은 목적지 주변 사진으로 이동한 다음 축하 안내를 표시합니다. 같은 목적지 안내를 닫은 뒤에도 버튼을 누르면 다시 확인할 수 있습니다.
- 다크 모드의 높낮이 제목과 ‘낮음 > 높음’ 문구는 `global.css`의 `.tour-screen--dark .tour-height-legend` 규칙으로 흰색을 적용합니다.
