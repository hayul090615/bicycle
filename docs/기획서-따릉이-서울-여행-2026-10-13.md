### 회사 검토용 핵심 제안

모바일 길 안내와 로드뷰 사전 탐색 기능을 안정화하고, 특정 자전거 코스 주변의 식당·카페·라이딩 관련 업체와 소규모 유료 제휴를 먼저 시도한다. 기본 길찾기는 무료로 제공하며, 제휴 광고의 노출·클릭 결과를 바탕으로 광고주가 계속 이용할 이유를 확인한다. 이후 관광 프로그램·자전거 행사 운영자를 위한 맞춤 코스 서비스로 확장하는 방안을 검토한다. 아래 비용·매출은 회사의 실제 결제 내역이 아닌 공식 요금과 명시한 가정으로 만든 검토 예산이다.

## 1. 기획 배경과 서비스 방향

처음에는 서울 따릉이 대여소 이름을 입력하며 지도 위 자전거를 이동시키는 타자게임을 만들고자 했다. 이후 대여소 위치와 잔여 자전거 수를 실제 데이터로 확인하고, 지도와 로드뷰를 통해 목적지까지의 길을 미리 살펴볼 수 있는 서비스로 기획을 확장했다.

현재 서비스의 중심은 **“어디에서 따릉이를 이용할 수 있는지 확인하고, 도착지까지 어떻게 이동할지 미리 알아보는 것”**이다. 이용자는 현재 위치 주변 대여소를 찾고, 목적지를 선택한 뒤 도보·자전거 경로와 예상 시간을 확인할 수 있다. 로드뷰에서는 경로 주변의 실제 촬영 사진을 살펴보며 이동 방향을 미리 익힐 수 있다.

기존 타자게임은 별도 화면의 부가 기능으로 유지한다. 서비스는 이미 공개되어 있으며, 모바일 화면의 겹침, 경로 표시와 도착 안내, 외부 데이터 연결을 계속 개선하고 있다.

### 기획 목표

- 이용 가능한 자전거가 있는 대여소를 확인할 수 있게 한다.
- 현재 위치에서 목적지까지의 이동 경로를 쉽게 이해하게 한다.
- 출발 전에 로드뷰로 갈림길과 주변 풍경을 미리 살펴볼 수 있게 한다.
- 모바일에서 지도와 버튼이 가려지지 않도록 필요한 목록만 열고 닫게 한다.
- 반납 시간과 주변 편의 정보를 함께 확인할 수 있게 한다.

## 3. 이용 흐름

**사이트 접속 → 내 위치 확인 → 대여소·잔여 대수 확인 → 도착지 선택 → 도보·자전거 경로 확인 → 로드뷰로 길 미리 보기 → 이용시간 확인 → 도착 안내**

1. 접속 시 자전거 애니메이션과 서울 지도를 보여준다. 위치 권한을 허용하면 현재 위치를 표시한다.
2. 주변 대여소와 잔여 자전거 수를 확인한다. 실시간 정보가 없으면 대여소 위치와 대수 확인 불가 상태를 표시한다.
3. 검색창에서 장소를 찾거나 지도에서 원하는 지점을 눌러 도착지를 정한다.
4. 이용 대여소까지의 도보 경로와 목적지까지의 자전거 경로, 이동 거리와 예상 시간을 확인한다.
5. 로드뷰를 열어 거리 사진과 지도 경로를 함께 보고, 다음 촬영 지점으로 이동하며 길을 살펴본다.
6. 필요하면 1시간 또는 2시간 이용시간을 선택해 카운트다운을 시작한다.
7. 이동 중에는 원형 버튼으로 길 안내 목록을 접거나 펼치며 지도를 확인한다.
8. 실제 GPS 도착 조건이 충족되면 축하 문구와 폭죽 안내를 표시한다. 로드뷰의 도착 버튼은 목적지 주변 사진으로 이동하는 사전 체험 기능이다.

## 4. 현재 구현 기능

### 4-1. 대여소와 잔여 자전거 정보

- 서울시 따릉이 데이터를 이용해 대여소 위치와 잔여 자전거 수를 조회한다.
- 대여소는 별도 분류 버튼을 누르지 않아도 지도 중심 500m 이내에 기본 표시한다.
- GPS 위치를 확인하고 주변 대여소까지 이동할 도보 경로를 안내한다.
- 실시간 조회 실패 시 포함된 대여소 위치 자료를 사용하고, 잔여 대수는 확인 불가로 표시한다.

### 4-2. 도착지 선택과 자전거 길 안내

- 현재 위치를 출발지로 사용하고, 서울 지도 선택 또는 장소 검색으로 도착지를 정한다.
- 출발·도착 위치를 핀으로 구분하고 경로 끝의 이동 방향을 화살표로 표시한다.
- 외부 경로 서비스에서 받은 자전거 경로와 예상 거리·시간, 구간별 회전 안내를 표시한다.
- 조회한 후보 경로는 예상 시간이 짧은 순서로 비교한다. 자료가 있을 때 가까운 길과 신호등이 적은 길을 선택할 수 있다.
- 추천 코스 검색, 코스 종류·주행 시간·평탄한 강변 코스 선택, 경로 고도와 오르막·내리막 정보도 제공한다.
- 길 안내 목록은 상단 버튼과 모바일 원형 버튼으로 접고 펼칠 수 있다. 모바일에서 새 도착지를 고르면 목록을 먼저 접어 지도를 보여주고, 원형 버튼을 눌러 열 수 있다.

### 4-3. 로드뷰로 이동 경로 미리 보기

- 지도에서 선택한 촬영 지점의 거리 사진을 연다.
- 기본 화면은 지도와 로드뷰를 절반씩 표시한다. 데스크톱은 좌우, 모바일은 위아래로 나누며 전체화면 버튼도 제공한다.
- 선택한 목적지 경로를 로드뷰의 파란 안내선으로 표현하고, 시점과 촬영 위치 변화에 맞춰 갱신한다.
- 앞으로 보이는 경로를 이어서 그리고, 다음 촬영 지점으로 이동할 수 있게 한다.
- 나침반으로 북쪽을 맞추거나, 권한이 허용된 휴대폰의 방향을 따라 화면을 회전할 수 있다.
- 도착 버튼을 누르면 목적지 주변 촬영 지점으로 이동한 뒤 축하 안내를 보여준다.

로드뷰는 촬영 사진으로 구성된 사전 탐색 화면이다. 파란 안내선은 촬영 위치·시점과 경로를 이용한 근사 표현이며, 모든 사진에서 실제 노면을 정확히 인식한 결과는 아니다. 사진에 없는 구간이나 가림·촬영 각도에 따른 표현은 계속 개선한다.

### 4-4. 지도와 주변 장소

- 일반 지도·스카이뷰·3D 화면을 전환하고, 서울 서비스 권역은 노란 점선으로 둘러 표시한다.
- 권역 안쪽은 선명하게, 바깥 지역은 살짝 흐리게 표현한다. 지나치게 먼 지역까지 축소하지 않도록 지도 범위를 제한한다.
- 식당·카페·편의점·화장실·명소·신호등·CCTV를 가로 분류 버튼에서 한 종류씩 선택한다.
- 일반 주변 정보는 지도 중심 500m 이내, CCTV는 실제 GPS 위치 20m 이내의 등록 자료를 표시한다.
- 식당 표시는 마우스를 올리거나 모바일에서 누르면 이름·주소·거리와 후기 팝업을 연다.
- 네이버 블로그 검색 링크를 제공하며, API 키가 설정되면 관련 블로그 글을 자동으로 조회한다.
- 별점은 글쓴이가 명시한 5점 만점 점수와 출처를 함께 표시한다. 점수가 없으면 ‘별점 정보 없음’으로 표시한다.

### 4-5. 반납 시간과 도착 안내

- 1시간·2시간을 누르면 디지털 타이머가 바로 시작되고, 종료 버튼으로 멈출 수 있다.
- 페이지가 열려 있고 알림 권한이 허용되면 만료 5분 전과 만료 시점에 알림을 제공한다.
- 실제 도착은 최근 GPS의 거리·정확도와 연속 관측을 확인하여 판정한다.
- 도착 시 배경을 어둡게 하고 ‘안전운전 수고하셨습니다.’ 문구와 폭죽을 보여준다.

### 4-6. 처음 방문 안내와 부가 기능

- 처음 방문 시 버튼 사용법을 설명하는 튜토리얼을 제공한다. 이전·다음과 닫기 버튼을 사용할 수 있다.
- 브라우저 방문 기록을 저장해 재방문 시 튜토리얼을 생략한다. 서버와 계정 방문 기록 연동 코드도 준비되어 있다.
- 광고는 재방문에도 표시하며, ‘24시간 동안 보지 않기’를 선택하면 해당 기간 숨긴다.
- 임시 광고 3개를 이전·다음 버튼과 선택 점으로 바꿔 볼 수 있다.
- 한국어를 기본으로 하고, 영어 전환과 선택 언어 유지, 다크·라이트 모드를 제공한다.
- 타자게임에서는 서울 25개 자치구 대여소 이름 입력, 점수·정확도·콤보·진행률, 일시 정지, 결과와 브라우저 최고 점수를 제공한다. 문장 타자 연습도 이용할 수 있다.

## 6. 현재 제공 범위와 연동 상태

| 항목 | 현재 상태와 기획서에 쓸 표현 |
| --- | --- |
| 잔여 자전거 수 | 서울시 실시간 API가 응답할 때 조회 결과를 표시한다. 조회 실패 시 대수를 추정하지 않는다. |
| 자전거 길 안내 | 경로 서비스가 제공한 후보를 비교한다. 모든 도로에서 절대적인 최단 시간이나 실시간 교통 최적화를 보장하는 기능은 아니다. |

| 반납 타이머 | 이용자가 직접 시작하는 알림이다. 실제 따릉이 대여 기록과 자동 연결되어 있지 않다. |
| 식당 블로그 후기 | 검색 링크는 제공 중이다. 팝업의 자동 글 조회는 네이버 API 키 설정이 필요하다. |
| 식당 별점 | 블로그 글쓴이가 명시한 점수만 사용한다. 네이버 공식 매장 종합 평점을 가져오는 기능은 아니다. |

| 방문 기록 | 브라우저 기록으로 튜토리얼 재표시를 제어한다. 서버 DB 저장은 연결 설정에 따라 활성화된다. |
| 광고 | 현재는 임시 콘텐츠 3개다. 실제 광고주·광고 수익 운영은 아직 연결하지 않았다. |

서울시 따릉이 공식 문서의 1,000건 제한은 한 번에 조회하는 건수다. 해당 문서에는 별도의 일일 호출 한도가 명시되어 있지 않으므로, 일일 한도가 없다고 단정하지 않는다. 현재 구현은 나눠 조회하고 결과를 잠시 재사용한다.

## 7. 계속 수정할 항목과 다음 개발 방향

2. **경로와 도착 정확도:** 다양한 GPS 상태와 도착지에서 도착 판정·핀 위치를 확인하고, 경로 서비스가 반환한 후보 비교와 실패 안내를 다듬는다.

5. **운영 관리:** API 중복 호출과 이용량을 확인하며 조회 속도, 갱신 상태, 오류 안내를 개선한다.

타자게임은 부가 기능으로 계속 유지한다. 이후 추가 기능이나 화면 변경은 이용자 요청과 모바일 사용 흐름을 기준으로 결정한다.

### 10-3. 회사 인건비와 변동 비용

운영 비용에는 개발·유지보수·제휴 관리에 쓰는 직원 시간도 포함한다. 예를 들어 월 10시간을 투입하고 사내 시간당 비용을 30,000원으로 가정하면 월 300,000원이다. 인프라 기본안 70,000원과 합치면 **월 370,000원**이 된다. 광고·영업비를 월 100,000원 더 쓰는 예산에서는 월 470,000원이다. 인프라 예산을 월 100,000원으로 잡으면 인건비 포함 기준은 월 400,000원으로 올라간다.

이미 사용한 개발 인건비는 실제 작업 시간과 회사 단가로 별도 집계한다. 추가 기능 개발비도 ‘예정 작업 시간 × 사내 시간당 비용’으로 산정한다. 예를 들어 20시간 × 30,000원 = 600,000원이며, 이는 계산 예시다. 큰 기능을 계속 개발하는 기간에는 월 10시간 운영 가정보다 더 많은 비용이 필요하다.

지도·로드뷰·장소 검색·경로 조회의 호출 수를 방문자 수와 따로 집계한다. 한 사람이 화면을 여러 번 움직이면 조회가 여러 번 발생할 수 있다. 무료 구간을 넘거나 유료 공급자로 전환하면 API 사용료를 추가한다. 예를 들어 **유료로 집계되는 자전거 경로 호출 10,000건 × 10원 = 100,000원**이다. 이 예시는 카카오 REST API를 선택한 경우의 계산이며, 현재 제공자의 비용을 뜻하지 않는다.

OSM 표준 지도 타일은 이용 정책을 따르는 공개 인프라이며 상업 서비스에 대한 계속 제공을 보장하지 않는다. 회사 운영 단계에서는 지도 타일과 현재 외부 경로 서비스의 사용 조건·운영 안정성, 필요 시 유료 제공처 비용을 확인한다. [OSM 타일 정책](https://operations.osmfoundation.org/policies/tiles/).

### 10-4. 비용 관리 방법

- API 요청 수·응답 시간·실패율과 월 결제 금액을 함께 확인한다.
- 중복 조회 방지와 짧은 결과 재사용을 유지하고, 지도 이동 중 요청이 과도하게 발생하지 않도록 한다.
- 회사 관리자만 결제·배포 권한을 갖도록 역할을 정하고, 필요한 유료 좌석 수를 확인한다.
- 서버 비용 알림과 초과 사용 대응 기준을 설정한다. 기능이 갑자기 중단되는 방식의 상한은 사용자 안내까지 함께 검토한다.
- 특정 지도 화면이나 외부 API의 호출이 비용을 크게 늘리는지 확인한 후 공급자 변경을 결정한다.

## 11. 수익 창출 방안

### 11-1. 우선 제안: 지역 업체 제휴 광고

자전거 코스 주변의 식당·카페·편의시설 운영자, 자전거 수리점이나 라이딩 용품 업체에 월 단위 광고 상품을 제안한다. 광고에는 매장 소개·영업 정보·쿠폰이나 이벤트 링크를 담고, 노출 수·상세 페이지 클릭 수·쿠폰 사용 결과 등을 계약한 범위에서 보고한다.

초기에는 특정 코스 주변에서 협력 업체 3곳을 모집해 한 달 동안 시험 운영하는 방안을 추천한다. **업체당 월 50,000원**은 첫 상품 검토용 가격 가정이다. 실제 광고주 반응과 노출량을 확인한 후 가격·기간·제공 내용을 확정한다. 현재 광고 3개는 임시 콘텐츠이며 유료 광고 계약이나 확보된 매출을 의미하지 않는다.

제휴 장소에는 광고·협찬 표시를 붙이고, 일반 식당 정보와 후기의 출처를 구분해 보여준다. 별점은 실제 자료를 유지한다. 팝업 광고의 크기·빈도와 24시간 숨김 기능은 모바일 지도 사용을 고려해 정한다.

### 11-2. 다음 단계: 기업·행사 운영자용 맞춤 서비스

관광 프로그램 운영사, 자전거 행사 주관사, 숙박업체 등이 이용할 수 있는 맞춤 코스 안내 페이지와 운영 지원을 제안한다. 계약 상품은 ‘초기 제작비 + 운영·유지보수비’로 나누고, 필요한 코스 수·제작 시간·지원 수준·API 비용을 계산해 견적을 제시한다.

회사 로고, 행사 안내, 추천 장소와 방문 링크, 운영 결과 집계 등은 후속 개발 항목이다. 기존 기능으로 시범 사용 가능한 범위를 먼저 확인한 뒤 유료 계약 범위를 정한다. 공공기관이나 기업의 도입·계약이 확정된 상태는 아니다.

### 11-3. 보조 수익: 배너 광고와 선택형 유료 기능

- **광고 네트워크 배너:** 실제 노출 규모가 확인된 이후 검토한다. 예를 들어 광고 1,000회 노출당 지급액을 3,000원으로 가정하면 월 10,000회 노출은 30,000원, 월 100,000회는 300,000원이다. 이는 계산 예시이며 실제 광고 단가나 수익을 보장하지 않는다.
- **선택형 유료 기능:** 코스 저장·여러 라이딩 계획 관리·광고 없는 화면 등에 대한 이용 의향을 확인한 뒤 검토한다. 현재 결제나 구독 기능은 구현되어 있지 않다.
- **제휴 판매 링크:** 라이딩 용품이나 체험 프로그램의 실제 제휴 계약이 생기면 판매 수수료 모델을 검토한다. 상품 공급·정산·환불·고객 문의 역할을 계약에서 정한다.

광고 네트워크를 도입할 때는 공급자가 지원하는 배너 배치로 설계하고, 지도 버튼과 광고가 겹치지 않도록 한다. 팝업창·클릭 유도·광고와 콘텐츠 구분에 관한 공급자 정책을 확인한 뒤 도입한다. 현재 임시 광고 화면에 광고 코드를 연결할지는 해당 방식의 적합성을 확인한 뒤 결정한다. [Google 광고 게재위치 정책](https://support.google.com/adsense/answer/1346295?hl=en).

| 8곳 | 400,000원 | 370,000원 | 30,000원 |
| 10곳 | 500,000원 | 370,000원 | 130,000원 |

이 가정에서는 협력 업체 8곳부터 표에 넣은 비용을 충당할 수 있다. 광고·영업비를 월 100,000원 추가하면 비용이 470,000원이 되어 10곳이 필요하다. 계산상 잔액은 모든 비용을 반영한 회사 순이익을 의미하지 않는다.

## 12. 회사에서 먼저 실행할 운영안

### 1단계: 기능 확인과 운영 기준 정리

모바일 원형 목록 버튼, 도착 안내, 로드뷰 전환과 잔여 대수 조회를 실제 이용 흐름에서 확인한다. 회사의 현재 서버 요금제·API 계정·결제 담당자를 정리하고, 네이버 키와 방문 기록 DB의 연결 상태를 확인한다.

### 2단계: 한 코스에서 한 달간 유료 제휴 실험

관심 지역의 코스 하나를 정하고 주변 업체 3곳에 상품을 제안한다. 광고 내용·금액·기간·노출 위치·보고 항목을 합의한 뒤 운영한다. 다음 지표를 측정하며, 수치 목표는 실제 방문량 확인 후 정한다.

- 방문자 중 도착지 선택과 길찾기를 끝낸 비율
- 로드뷰 사용 비율과 화면 오류·조회 실패율
- 재방문 비율과 목록·타이머 사용 흐름
- 제휴 광고 노출·상세 클릭·확인 가능한 쿠폰 사용
- 업체의 재계약 의향과 회사 직원의 실제 운영 시간

### 3단계: 확대 여부 결정

업체 재계약 의향, 실제 이용 결과와 운영비를 비교해 제휴 확대·가격 조정·기업용 맞춤 상품 개발을 결정한다. 업체 수만 늘려 매출을 계산하지 않고, 업체가 얻은 결과와 서비스 유지에 필요한 시간을 함께 확인한다.

**추천 방향:** 기본 길찾기·대여소 정보는 무료로 제공하고, 초기 수익은 지역 제휴 광고로 검증한다. 실제 이용과 제휴 성과가 확인되면 맞춤 코스 운영 서비스로 확장한다.

## 13. 기획서에 바로 옮길 요약문

본 프로젝트는 서울시 공공자전거 따릉이 대여소 데이터를 활용한 모바일 중심 자전거 이동 안내 웹서비스이다. 처음에는 대여소 이름을 입력하며 지도 위 자전거를 움직이는 타자게임으로 시작했으며, 현재는 주변 대여소의 잔여 자전거 수 확인과 목적지 길찾기, 로드뷰 사전 탐색을 중심으로 서비스를 확장하였다. 이용자는 현재 위치에서 가까운 대여소를 확인하고 도착지를 선택한 뒤, 도보·자전거 경로와 거리·예상 시간을 살펴볼 수 있다. 로드뷰에서는 거리 사진과 파란 경로 안내를 통해 이동할 길을 미리 확인한다. 반납 시간 알림, 주변 식당·편의 정보, 튜토리얼과 타자게임도 제공한다. 현재 주요 기능을 구현하여 공개한 상태이며, 모바일 화면 구성과 경로 표현, 도착 안내 및 외부 데이터 연동을 계속 수정하고 있다.

회사 운영 비용은 서버·데이터베이스·도메인·API 사용료와 직원의 개발·관리 시간을 포함하여 관리한다. 초기에는 기본 이동 안내를 무료로 제공하고, 자전거 코스 주변 업체의 유료 제휴 광고를 통해 수익 가능성을 확인한다. 이후 행사·관광 프로그램 운영자를 위한 맞춤 코스 서비스로 확장하는 방안을 검토한다. 비용과 매출은 실제 계약·사용량·운영 시간으로 검증하며, 현재의 예산과 매출 계산은 검토를 위한 가정이다.
